# 言葉 Kotoba — японские карточки

Карточки для изучения японских слов, как в Quizlet: картинка и слово (кандзи, если есть, иначе кана).
Нажимаешь на карточку, и появляются хирагана, перевод на русский и кнопка озвучки.

Работает в браузере на телефоне и компьютере, ставится на главный экран как приложение и работает без интернета.
Бесплатно: без сервера, без аккаунтов, без платных API.

## Что умеет

- **Колоды** и **карточки**: картинка + кандзи/кана + чтение + перевод.
- **Добавление карточки**:
  - поиск по японско-русскому словарю: `ookami`, `おおかみ`, `狼` или `волк` — поля заполнятся сами;
  - ромадзи превращается в кану прямо при вводе;
  - картинку можно загрузить файлом, перетащить, вставить из буфера (Ctrl+V) или по ссылке, затем обрезать под карточку.
- **Добавление списком**: одна строка — одна карточка (`слово`, `слово; перевод` или `кандзи; чтение; перевод`).
- **Режимы изучения** (в обе стороны: японский → русский и русский → японский):
  - *Карточки*: листать, переворачивать, смахивать «знаю / не знаю»;
  - *Повторение*: интервальное, как в Anki; приложение само решает, что показать сегодня;
  - *Тест: выбор* из 4 вариантов;
  - *Тест: письмо*: написать перевод или чтение (опечатки прощаются, спорный ответ можно засчитать).
- **Озвучка** голосом устройства (Web Speech API).
- **Резервная копия**: экспорт и импорт в файл `.json`, так же карточки переносятся между устройствами.

## Где хранятся данные

Только в браузере на устройстве (IndexedDB). Карточки, добавленные на компьютере, сами на телефон не попадут:
перенесите их через **Настройки → Сохранить копию** на одном устройстве и **Загрузить из файла** на другом
(или через меню колоды: «Поделиться колодой»).

На телефоне обязательно **установите приложение на главный экран**. Иначе браузер (особенно Safari на iPhone)
может очистить данные сайта, если его долго не открывать.

## Запуск на компьютере

Нужен только Python (любой 3.x):

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173. На localhost офлайн-кэш отключён, чтобы правки были видны сразу;
проверить его можно, добавив `?sw` к адресу.

## Публикация на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com и создайте **публичный** репозиторий, например `kotoba`.
2. Загрузите в него файлы проекта: «Add file → Upload files» и перетащите содержимое папки
   (папки `tools/` и `.claude/` загружать не обязательно).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/kotoba/`.
   Откройте его на телефоне и добавьте на главный экран.

### Как выпустить обновление

После любых изменений в файлах **обязательно** обновите список офлайн-кэша, иначе телефон продолжит показывать старую версию:

```bash
python tools/build_sw.py
```

Затем загрузите изменённые файлы (включая `sw.js`) на GitHub. В приложении появится кнопка «Обновить».

## Структура

```
index.html, manifest.webmanifest, sw.js   — страница, манифест приложения, офлайн-кэш
css/style.css                             — оформление
js/app.js                                 — запуск и маршруты
js/db.js                                  — хранилище (IndexedDB), экспорт/импорт
js/dict.js                                — поиск по словарю
js/srs.js                                 — интервальное повторение
js/views/*.js                             — экраны
vendor/                                   — Preact + htm, wanakana (без сборки)
data/dict.json                            — словарь (≈70 тыс. слов, 1,8 МБ в сжатом виде)
starter/                                  — стартовая колода «Первые слова»
tools/                                    — скрипты: словарь, иконки, офлайн-кэш
```

Пересобрать словарь из свежего JMdict (скачайте `jmdict-rus-*.json` и `jmdict-eng-*.json`
с https://github.com/scriptin/jmdict-simplified/releases):

```bash
python tools/build_dict.py jmdict-rus.json jmdict-eng.json
```
